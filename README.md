#  RaidTalk Theme

Тёмная пользовательская тема ALBEDO для веб-приложения [app.raidtalk.ru](https://app.raidtalk.ru).

## Установка через Stylus

1. Установите расширение **Stylus** для своего браузера.
2. Откройте [файл темы](https://raw.githubusercontent.com/vertuozi92/ALBEDO-RaidTalk-Theme/main/raidtalk-albedo.user.css).
3. Stylus предложит установить стиль — подтвердите установку.
4. Откройте или обновите [RaidTalk](https://app.raidtalk.ru).

Если браузер просто показывает текст CSS, откройте страницу файла на GitHub и нажмите **Raw**. При установленном Stylus обычно появляется предложение установить стиль.

## Обновление

Когда в репозитории появится новая версия, откройте Stylus → управление стилями и обновите стиль, если автоматическое обновление не сработало.

## Примечание

Тема меняет только визуальное оформление сайта средствами CSS. Она не добавляет серверных функций и не меняет данные аккаунта. Если интерфейс RaidTalk изменится, отдельные CSS-селекторы могут потребовать обновления.

## Авторство

**ALBEDO** — пользовательская тема для RaidTalk.
